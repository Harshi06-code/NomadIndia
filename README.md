# NomadIndia

NomadIndia is a desktop travel and adventure activity exploration platform built using HTML, CSS, JavaScript, and Electron. The application allows users to discover exciting adventure destinations across India and explore activities such as paragliding, rafting, trekking, scuba diving, and more.

This project demonstrates how web technologies can be used with Electron to build a desktop application for exploring travel destinations and booking adventure activities.



## Features

* Explore adventure destinations across India
* Browse activities such as paragliding, rafting, trekking, and scuba diving
* Dedicated pages for each location and activity
* Booking pages for selected destinations
* Image gallery showcasing destinations and activities
* Desktop application built using Electron



## Technologies Used

* HTML
* CSS
* JavaScript
* Electron
* Node.js

## How to Run the Project

1. Clone the repository

git clone https://github.com/Harshi06-code/NomadIndia.git

2. Navigate to the project folder

cd NomadIndia

3. Install dependencies

npm install

4. Start the Electron application

npm start
